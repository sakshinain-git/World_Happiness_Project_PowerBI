# 🌍 World Happiness Report – Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Power BI Dashboard** based on the **World Happiness Report** dataset.

The dashboard analyzes happiness scores across countries and explores their relationship with factors such as **GDP per capita, social support, and other country-level indicators**.

The goal of this project is to transform raw data into meaningful and interactive visual insights using Microsoft Power BI.

---

## 🎯 Project Objectives

- Analyze happiness scores across different countries.
- Identify countries with the highest and lowest happiness scores.
- Compare GDP per capita with happiness scores.
- Analyze social support across countries.
- Visualize country-wise data geographically.
- Create an interactive and user-friendly dashboard.
- Practice data cleaning, transformation, DAX, and data visualization.

## 📌 Dashboard Features

### 🔹 KPI Cards
Displays important indicators such as:
- Country with Highest GDP
- Country with Highest Happiness Score
- Country with Lowest Corruption

### 🔹 Happiness Score Table
Shows countries along with their respective happiness scores.

### 🔹 GDP vs Happiness Score
A scatter plot used to analyze the relationship between GDP per capita and happiness score.

### 🔹 Countries with Top Score
Displays countries with the highest happiness scores using a bar chart.

### 🔹 Countries with Lowest Score
Highlights countries with the lowest happiness scores.

### 🔹 Country Map
Provides a geographical representation of countries included in the dataset.

### 🔹 GDP per Capita by Country
Compares GDP per capita values across different countries.

### 🔹 Social Support by Country
A treemap visualization showing social support values by country.

### 🔹 Interactive Filter
A country/region slicer allows users to interactively filter the dashboard.

---

## 📈 Key Insights

- Finland has the highest happiness score among the countries displayed in the dashboard.
- Nordic countries such as Finland, Denmark, Norway, Iceland, and Sweden appear among the countries with high happiness scores.
- The scatter plot shows the relationship between GDP per capita and happiness score.
- GDP per capita varies significantly across countries.
- Social support is another important factor represented in the dashboard.

> **Note:** Insights are based on the dataset used for this project and may vary depending on the report year and data source.
